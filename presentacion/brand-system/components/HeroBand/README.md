# HeroBand

Bloque de apertura sobre `primary-deep`, centrado: eyebrow cian, título `display` en blanco, bajada al 75% de blanco y hasta tres CTA grandes.

- Es índigo en ambos temas; el texto sobre él es siempre blanco o `brand-cyan`.
- Orden de CTA: lima (campaña), vidrio (acción neutra), primario con halo (acción principal del público).
- En móvil el título baja a 26px/1.15.
