# ChoiceTile

Botón ancho de borde fino y `radius-2xl` con el que el visitante declara su intención en primera persona («Quero…», «Sou…»).

- Texto 14px semibold en `foreground`; ícono en cuadro `secondary` de 32px con `radius-xl`.
- Hover: borde `primary`. Alto mínimo 56px.
- El consumidor aporta el ícono (los del preview son marcadores) y la acción.
