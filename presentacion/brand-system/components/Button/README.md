# Button

Botones y enlaces de acción de Sinaxys: un primario violeta por vista, outline para la alternativa y CTA grandes con halo sobre el hero.

| Variante | Clases | Cuándo |
| --- | --- | --- |
| Primario | `sx-btn sx-btn--primary` | Acción principal: «Agendar demo», «Aceitar». Hover: `brand-pay`. |
| Outline | `sx-btn sx-btn--outline` | Alternativa junto al primario: «Recusar», «Entrar na minha conta». |
| Outline primario | `sx-btn sx-btn--outline-primary` | Acción secundaria de marca sobre blanco. |
| CTA grande | `sx-btn--lg` + `--lime`, `--glass` o `--primary sx-btn--glow` | Solo sobre `primary-deep` (hero). Lima para la campaña destacada, vidrio para la acción neutra. |
| Enlace | `sx-link` | «Comparar soluções →»; la flecha se separa al pasar el mouse. |

- Alto mínimo 44px (táctil). Texto en verbo + objeto, PT-BR, sin punto final.
- Una sola acción lima por pantalla.
- El consumidor aporta el ícono (flecha →) y el destino del enlace.
