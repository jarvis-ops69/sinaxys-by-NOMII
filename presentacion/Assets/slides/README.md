# Assets de referencia de las slides

Este directorio contiene las **43 imágenes descargadas desde la página estratégica de Notion** de Sinaxys. Son assets de referencia visual para construir la presentación; no deben publicarse, modificarse ni reutilizarse fuera de este proyecto sin la validación de Sinaxys/NOMII y de los titulares de cada imagen.

## Cómo usarlos

- `01-...png` a `33-...png`: referencias de la secuencia original de campaña, contenido, web y marca.
- `34-...png` a `43-...png`: referencias visuales de Lead-to-Client Funnel ya propuestas en Notion.
- `asset-manifest.json`: mapea cada asset al bloque de Notion, a su contexto de slide, hash SHA-256 y tamaño de descarga.

## Regla para Claude

Estas imágenes son una referencia de **lenguaje visual y composición**. No son una instrucción para replicar cada layout literalmente ni una autorización para alterar logos, testimonios, personas o claims. Mantener la lógica: fondo claro, violeta Sinaxys, jerarquía editorial, tarjetas redondeadas, diagramas de flujo y baja densidad de texto.
