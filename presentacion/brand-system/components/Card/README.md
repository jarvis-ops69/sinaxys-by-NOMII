# Card

Tarjeta blanca de esquinas amplias (`radius-3xl`, borde `border`, `shadow-card`, padding `space-6`) para cifras y bloques de contenido.

- Estructura de cifra: `sx-eyebrow` → `sx-card__stat` (48px, números tabulares, `primary`) → `sx-card__text` en `muted-foreground`.
- Variante de contenido: eyebrow → título `heading-3` → texto. Usa solo cifras publicadas por Sinaxys, con su fuente.
- Sobre fondo `muted` o blanco; en grilla con gap `space-4`.
