# Eyebrow

Antetítulo corto en mayúsculas que sitúa el título siguiente (estilo `eyebrow`: 11px, 700, tracking 0.18em).

- `sx-eyebrow` en `primary` sobre fondo claro; `sx-eyebrow--cyan` (`brand-cyan`) sobre `primary-deep`.
- Dos a cinco palabras que nombran la sección o el público: «PLATAFORMA», «SINAXYS EM NÚMEROS».
- Va siempre seguido de un título; nunca solo.
